The file has the columns question_id,correct. Each value is 0 or 1, and a blank value means the model gave no answer. You can download the template or a sample from a held-out paper model.
The file has the columns question_id,e0,…,e767. Each row holds the BAAI/bge-base-en-v1.5 embedding of one answer, with attention-mask mean pooling over the last 512 tokens and L2 normalisation. You can download the template (about 1 MB).
How to collect answers
  • Collect one answer per question with the prompt as given.
  • Use greedy decoding with up to 3,072 new tokens.
  • For reasoning models, use temperature 0.6, top-p 0.95 and top-k 20 with up to 12,288 tokens.
  • The author responses found that a system prompt moves a model's position. Reference and query answers must therefore share a system prompt.
  • The author responses also found that temperature does not move a model's position.
  • The file questions.csv lists the question ids, their benchmarks and their pool membership.
  • The code release holds the prompts, gold answers and graders in data/core/probe.jsonl.
  • The encoder reads the 900 pool questions and ignores the rest. Your model must answer at least 50 of them.

    How it works

    • BULLPEN embeds a model from its answers to a fixed probe.
    • The embedding reads the model's correctness bits, the mean embedding of the questions it got right (weighted by correctness) and the mean BGE embedding of its own answers.
    • A closed-form multi-block PLS-SVD fits loadings for each of these channels. The method z-scores each channel's scores and concatenates them.
    • BULLPEN-fused has 12 + 10 + 10 dimensions. BULLPEN-bits+q has 16 + 16 dimensions and uses only the bits and the question text.

    This demo

    • This demo fits the released code on fold 0, seed 0 of the paper's strict protocol. The protocol groups models into folds by publisher and uses 900 pool questions.
    • The fold has 208 training models and 52 held-out models.
    • The paper's fold-in places a new model. It solves a ridge regression of the model's observed bits on the frozen bit loadings, builds the question block from those bits and projects the mean answer embedding.
    • Every map is linear, so the page evaluates the maps from exported weights and runs no language model.
    • The heads are the paper's battery readouts. They use standardised ridge regression, with logistic regression for base vs chat, and this demo refits them once on the training models.
    • The middle view shows a PCA of the 260 placements in the selected space. The PCA is linear, so the page projects an uploaded model exactly.
    • The view scales each axis to its 2nd to 98th percentile range to fill the pane. Points outside that range sit on the edge of the frame.
    • The page finds nearest neighbours by cosine similarity in the full 32-d space.

    Limits

    • The submission scores the heads on held-out models from the 260 open-weight models.
    • The author responses add nine closed models that were placed without refitting (see Reported results).
    • This demo shows one split and one seed, so each per-model value is a single draw. The paper averages over 15 runs.
    • The base-vs-chat label comes from the model name, as in the paper.
